Theo dõi task

Quy tắc đóng task

  1. Source-ready và owner rõ, unknown bắt buộc được giải quyết.
  2. Code + UI mới chạy từ normal entry, package/asset/save wiring đầy đủ.
  3. Required tests, harness, matched captures và device/provider evidence đúng revision.
  4. Review evidence và cập nhật plan.json; tái tạo HTML. Ghi chú browser không tự ghi repo hoặc đổi official progress.

Các blocker còn giữ: AES level data, fail/revive source, level8/13/29, event/advanced rules, capture timing/audio và production gateways. Đọc chi tiết từng task; không bỏ task để tăng %.

Offline HTML · không gọi dịch vụ ngoài · localStorage tùy browser/file origin · Export để giữ ghi chú qua đổi máy. Weight là kích thước tương đối, không phải ngày hay % giống game.
